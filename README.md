# Absorbent

Превращает запись онлайн-лекции (скринкаст `*.mkv`/`*.mp4` или аудиофайл) в
качественный конспект в Markdown: структурированный текст по транскрипту,
слайды-иллюстрации из видео и презентации лектора, формулы в LaTeX. Готовый
`notes.md` рядом с исходником, изображения — в соседнем каталоге `images/`,
документ можно сразу отдавать в pandoc.

Конвейер устроен так:

1. из видео через ffmpeg извлекаются кадры с частотой `--fps` (по умолчанию
   один кадр в секунду); вход без видеопотока (аудиофайл) проверяется
   `ffprobe` и пропускает этот и следующий этап;
2. кадры отбираются по перцептивному хешу (pHash): сцена — отрезок подряд
   идущих кадров, каждый из которых не дальше `--hash-threshold` бит от
   первого кадра отрезка; из каждой сцены берётся ядро — кадр, ближайший к
   остальным её кадрам, а сцены короче `--min-scene-seconds` отбрасываются
   как анимация, промежуточные состояния и шум; похожие соседние ядра не
   дублируются;
3. презентация лектора (`--slides`: PDF, `.pptx`/`.odp`/…) растрируется в
   страницы с разрешением `--slides-dpi`: PDF разворачивается `pdftoppm`
   сразу, остальные форматы сначала конвертирует LibreOffice; страницы ложатся
   в `images/slide_NNN.png` рядом с кадрами видео;
4. речь распознаётся в транскрипт с таймкодами: локально через Whisper или
   облачно через Voxtral (Mistral), с диаризацией спикеров;
5. vision-модель описывает каждый ключевой кадр, получая на вход картинку,
   её таймкод и фрагмент транскрипта вокруг этого момента; страницы
   презентации описываются тем же вызовом, но без транскрипта: у страницы нет
   таймкода, поэтому модель получает картинку и номер («слайд 3 из 22»);
6. текстовая LLM синтезирует полный Markdown-конспект по транскрипту,
   описаниям кадров и страницам презентации, вставляя изображения
   `![подпись](images/frame_....jpg)` и `![Слайд N](images/slide_NNN.png)`
   ровно с теми именами файлов, что реально лежат на диске; пустой
   (или состоящий из пробелов) ответ модели считается ошибкой этапа:
   запрос повторяется один раз, а при повторной пустоте конвейер
   останавливается с диагностикой (`finish_reason`, расход токенов, длина
   reasoning) — пустой `notes.md` не записывается, HTML и PDF не собираются;
7. постпроцессинг: таблицы notes.md выравниваются скриптом
   `fmt-md-tables`, затем pandoc собирает самодостаточный `notes.html`
   (CSS-тема github-markdown, формулы MathML) и `notes.pdf` через движок
   lualatex со шрифтами DejaVu.

Провайдеры и модели задаются в одном YAML-файле; ключи API берутся из
переменных окружения; конкретная модель каждого этапа выбирается флагом
командной строки.

## Установка

Требуется [uv](https://docs.astral.sh/uv/), `ffmpeg` и `ffprobe` в PATH
(пакет `ffmpeg` в Arch Linux). CUDA-видеокарта необязательна — нужна только
для локального Whisper; без неё Whisper работает на CPU медленнее.

Для постпроцессинга (этап 7) нужны внешние инструменты:
`fmt-md-tables` (выравнивание таблиц), `pandoc`, движок `lualatex` и
шрифты DejaVu (кириллица). Без них конвейер работает до синтеза
notes.md; HTML/PDF отключаются флагом `--skip-render`.

Для презентаций (этап 3) нужны `pdftoppm` (пакет `poppler`) и — только для
не-PDF (`*.pptx`, `*.odp`, …) — `soffice` (LibreOffice). Без них `--slides` не
работает, но конвейер без презентаций от них не зависит.

```bash
uv sync
```

## Конфигурация

Конфигурация ищется в порядке: путь из `--config` → `./config.yaml` →
`~/.config/absorbent/config.yaml`. В репозитории лежит рабочий `config.yaml`
со схемой:

```yaml
providers:
  deepseek:                # OpenAI-совместимый провайдер
    base_url: https://api.deepseek.com
    api_key_env: DEEPSEEK_API_KEY   # имя переменной окружения с ключом
  llama-swap:              # локальный сервер (llama-swap на 127.0.0.1:12434)
    base_url: http://127.0.0.1:12434/v1
    api_key_env: ""        # пусто -> запросы без заголовка Authorization

stt:                       # распознавание речи
  whisper-turbo:           # локальный Whisper (по умолчанию)
    backend: whisper
    whisper_model: turbo
    default: true
  voxtral-transcribe-2:    # облачный Voxtral (Mistral), нужен MISTRAL_API_KEY
    backend: voxtral
    provider: mistral
    model: voxtral-mini-latest

vision:                    # описание кадров
  deepseek-v4-flash-vision-exp:
    provider: deepseek
    default: true

llm:                       # синтез конспекта
  deepseek-v4-flash:
    provider: deepseek
    default: true
```

Правила:

- `default: true` ровно в одной модели каждой категории (`stt`, `vision`,
  `llm`) задаёт модель по умолчанию;
- ключ API провайдера читается из переменной окружения, имя которой
  указано в `api_key_env`; пустое значение — запросы без авторизации
  (локальные серверы);
- если переменная задана в конфиге, но отсутствует в окружении, программа
  останавливается с ошибкой `missing env var <имя>`;
- у моделей `stt` с `backend: whisper` поле `whisper_model` задаёт модель
  openai-whisper; у облачных бэкендов поле `model` — id модели в API.

Необходимые переменные окружения:

- `DEEPSEEK_API_KEY` — для облачных моделей DeepSeek (vision/llm по
  умолчанию);
- `MISTRAL_API_KEY` — только если выбран `--stt voxtral-transcribe-2`.

## Использование

```bash
uv run absorbent lecture.mkv
```

Флаги:

| Флаг | Значение по умолчанию | Описание |
|---|---|---|
| `input` | — | путь к медиафайлу или директории (обрабатываются все файлы `.mp4 .mkv .webm .avi .mov .mp3 .wav .flac .ogg .m4a .opus`); без аргументов запускается мастер |
| `--config PATH` | поиск по умолчанию | путь к YAML-конфигурации |
| `--stt NAME` | дефолт из конфига | модель распознавания речи |
| `--vision-model NAME` | дефолт из конфига | модель описания кадров |
| `--llm-model NAME` | дефолт из конфига | модель синтеза конспекта |
| `--language {ru,en,auto}` | `auto` | подсказка языка распознавания речи; `ru/en` форсируют весь файл как один язык, `auto` — детекция (для двуязычных лекций всегда `auto`) |
| `--output-language {ru,en}` | `ru` | язык итогового конспекта и промптов; дословные RU/EN-фразы лекции сохраняются в оригинале |
| `--fps N` | `1` | частота извлечения кадров |
| `--hash-threshold N` | `10` | порог pHash-расстояния в битах: граница сцены и отсев похожих ядер, 0–64 |
| `--min-scene-seconds S` | `5` | минимальная длительность сцены, с: короче — анимация или промежуточное состояние (`0` — оставить каждый отрезок) |
| `--slides PATH` | — | презентация к лекции: PDF, `.pptx`/`.odp`/… (конвертируется LibreOffice) или каталог с ними; флаг можно повторять |
| `--slides-dpi N` | `150` | разрешение растеризации страниц презентации |
| `--skip-slides` | — | пропустить растеризацию и описание презентаций |
| `--output-dir DIR` | `<имя_файла>/` рядом с входом | каталог результата |
| `--flat` | — | результат и сырой транскрипт рядом с входным файлом (`<имя>.md`, `<имя>.json`, `<имя>.images/`), кэш — в `<каталог>/.absorbent/<имя>/` |
| `--force` | — | игнорировать кэш и перезапустить все этапы, включая синтез и постпроцессинг |
| `--skip-stt` | — | пропустить распознавание речи |
| `--skip-frames` | — | пропустить извлечение и отбор ключевых кадров |
| `--skip-describe` | — | пропустить описание кадров и страниц презентации |
| `--skip-synthesize` | — | пропустить синтез Markdown |
| `--skip-render` | — | пропустить постпроцессинг (таблицы, HTML, PDF) |

Неизвестное имя модели (`--stt`, `--vision-model`, `--llm-model`) печатает
список допустимых имён в этой категории и завершается с кодом 2.

Язык лекции и язык конспекта — независимые настройки. Лекции могут быть
двуязычными (например, речь почти целиком на английском с русскими
вставками): whisper возвращает один язык на весь файл, поэтому для таких
записей `--language` следует оставлять в `auto`. `--output-language`
определяет, на каком языке модель пишет описания кадров и конспект, а
дословные фразы и термины из транскрипта на другом языке (например,
русские цитаты в английской лекции) сохраняются в оригинале.

Если кадров вышло слишком много или слишком мало — перенастройте
`--min-scene-seconds` (для быстрой смены картинки на демонстрации экрана —
`2`, а `0` оставляет каждый отрезок и почти повторяет прежнее поведение;
для слайдов с анимацией — больше), `--hash-threshold` (меньше — больше
сцен) или `--fps`. Кадры кэшируются, повторный прогон без `--force` не
переизвлекает видео; при повторном отборе каталог `images/` и описания
приводятся к текущему набору кадров, а синтез и постпроцессинг
переиспользуют готовые `notes.md`, `notes.html` и `notes.pdf` (см. «Кэш
этапов»).

### Презентации лектора

Презентацию преподавателя конвейер не ищет сам: путь задаётся флагом
`--slides` (его можно повторять, можно указать каталог — тогда берутся все
PDF и офисные презентации из него):

```bash
uv run absorbent lecture.m4a --slides deck.pdf
```

Причина, по которой нет автоподбора по имени записи: в плоском режиме
absorbent сам пишет `<имя>.pdf` рядом с записью (это конспект), и такой файл
был бы принят за презентацию. Указанные страницы описываются по одной
(отсева почти одинаковых соседних страниц пока нет) и попадают в конспект
разделом «Слайды презентации» с меткой «слайд N» — в тот же вход, что и
кадры, поэтому модель сама сопоставляет страницу с речью по содержанию.
Разрешение растеризации меняет `--slides-dpi` (по умолчанию 150), а
`--skip-slides` пропускает этап целиком.

Презентации можно давать и к аудиозаписи без видеопотока: тогда в `images/`
лежат только `slide_NNN.png`, а каталогов кадров не появляется. Страницы
кэшируются в `.absorbent/slides/` и принимаются по подписи источника: правка
колоды или смена `--slides-dpi` заставляют растеризовать её заново.

## Мастер

Вызов без аргументов запускает интерактивный мастер:

```bash
uv run absorbent
```

Мастер обрабатывает одну запись за раз и последовательно спрашивает:
медиафайл (список медиафайлов текущего каталога, пункт «Другой каталог…» или
ручной путь — поэтому запись может лежать где угодно), презентации
(отметки в списке с автоподсказкой одноимённого файла, «Добавить слайды из
другого каталога…» и ручной путь), раскладку (`--flat` или каталог `<имя>/`),
язык конспекта и модель синтеза. По желанию открывается блок
«дополнительно»: язык и модель распознавания речи, модель описания, `--fps`,
`--hash-threshold`, `--min-scene-seconds`, `--slides-dpi`, `--force` и
`--skip-*`.

Перед запуском печатается сводка «Команда: absorbent …» — её можно
скопировать в терминал и повторить прогон без диалогов. Диалоги управляются
однообразно: Enter подтверждает, Esc отменяет шаг (в списках и полях ввода),
Ctrl-C отменяет мастер целиком. Отмена и отказ на последнем подтверждении
ничего не запускают: в stderr уходит «отменено», код завершения 130. Без
терминала (например, из скрипта) мастер не запускается: absorbent печатает
ошибку и возвращает код 2, а не зависает на вводе.

Обёртка `~/.local/bin/transcribe` пробрасывает дополнительные флаги, поэтому
презентацию можно указать и через неё:

```bash
transcribe lecture.m4a --slides deck.pdf
```

## Выходные файлы

Для входа `Lecture.mkv` (каталог результата по умолчанию — `Lecture/`):

```
Lecture/
  notes.md                  # итоговый конспект Markdown
  notes.html                # самодостаточный HTML (css и кадры встроены)
  notes.pdf                 # PDF через lualatex
  images/                   # ключевые кадры и страницы презентации, на которые
    frame_HH_MM_SS.jpg      # ссылается notes.md
    slide_NNN.png           # страницы из --slides (сквозная нумерация)
  .absorbent/               # кэш промежуточных результатов
    transcript.json         # [{start, end, text, speaker}]
    audio.wav               # извлечённое аудио (только voxtral)
    language.txt            # детектированный язык
    frames/                 # все извлечённые кадры до отбора ключевых кадров
    keyframes.json          # отобранные кадры: image/seconds/timestamp
    descriptions.json       # описания кадров vision-моделью
    slides/                 # растеризованные страницы и signature.json источника
    slide_descriptions.json # описания страниц презентации
```

`notes.md`, `notes.html`, `notes.pdf` и `images/` — результат; всё под
`.absorbent/` можно удалять без потери результата (кэш лишь ускоряет
повторные прогоны). `images/`, `frames/` и `lecture.images/` появляются
только у входа с видеопотоком или при `--slides`: аудиофайл без презентации
их не создаёт.

### Плоский режим (--flat)

Флаг `--flat` кладёт результат рядом с медиафайлом, без каталога `<имя>/`:

```
Lecture.mp4
Lecture.md                  # итоговый конспект Markdown
Lecture.json                # сырой транскрипт [{start, end, text, speaker}]
Lecture.html                # самодостаточный HTML
Lecture.pdf                 # PDF через lualatex
Lecture.images/             # ключевые кадры и страницы презентации, на которые
  frame_HH_MM_SS.jpg        # ссылается Lecture.md
  slide_NNN.png
.absorbent/
  Lecture/                  # кэш промежуточных результатов
    language.txt
    frames/
    keyframes.json
    descriptions.json
    slides/
    slide_descriptions.json
```

Ссылки на изображения в конспекте получают префикс `<имя>.images/`, поэтому
относительные пути остаются корректными; `--output-dir` и в этом режиме
задаёт каталог результата, а кэш всё равно ложится в
`<каталог входа>/.absorbent/<имя>/`.

### Кэш этапов

Признак готового этапа — его артефакт: `transcript.json` (распознавание),
`keyframes.json` (отбор кадров), `descriptions.json` (описание кадров),
`slide_descriptions.json` (описание страниц), `notes.md` (синтез). Страницы
презентаций принимаются по подписи источника в `.absorbent/slides/`
(канонический путь, размер, mtime и `--slides-dpi`), поэтому кэш страниц
переживает повторный прогон, а правка колоды его отменяет. Повторный прогон
без `--force` переиспользует готовые артефакты: `notes.md` не пересобирается,
а LLM не вызывается вовсе. Постпроцессинг пропускается, когда `notes.html` и
`notes.pdf` не старше `notes.md`, — правка конспекта руками заставляет
пересобрать обе версии.

Полный перезапуск — `--force`. Он же нужен, когда готовый результат больше
не соответствует настройкам: например, после смены `--output-language`,
`--llm-model` или набора `--slides` (`notes.md` переиспользуется как есть,
язык промпта синтеза в нём не записан).

### Вход без видеопотока

Если во входном файле нет видеопотока (mp3, m4a, wav), этапы извлечения и
отбора ключевых кадров пропускаются: конвейер печатает «кадров нет (аудио без
видеопотока)» и собирает конспект только по транскрипту, без иллюстраций.
Проверка выполняется `ffprobe` до запуска ffmpeg, поэтому аудиофайл не
завершается ошибкой извлечения кадров, а каталогов кадров (`images/` и
кэшевого `frames/`) не появляется вовсе. С `--slides` каталог `images/`
появляется, но содержит только страницы презентации — часто именно так и
работают с записью голоса и отдельной колодой слайдов.

## Постпроцессинг

После синтеза конвейер автоматически:
1. выравнивает таблицы `notes.md` внешним скриптом `fmt-md-tables`;
2. собирает самодостаточный `notes.html` через
   `pandoc --standalone --embed-resources` — CSS-тема github-markdown
   (файл в `src/absorbent/assets/github-markdown.css`, лицензия MIT,
   sindresorhus), изображения встроены как data-URI, формулы — MathML;
3. собирает `notes.pdf` через `pandoc --pdf-engine=lualatex` со шрифтами
   DejaVu; первый заголовок notes.md становится title.

Обе версии наследуют от шаблонов pandoc дефекты вёрстки, поэтому рядом с
ними подкладывается своя надстройка.

HTML (`render._page_css`):
- фон `html` берётся из того же github-markdown.css, что и тема конспекта:
  без этого штатный белый фон даёт белые поля вокруг тёмной полосы текста;
- штатное ограничение полосы `body { max-width: 36em }` снимается, полоса
  контента расширяется до `HTML_COLUMN_PX` (1280 px) и сжимается по
  `clamp(1rem, 4vw, 4rem)` на узких экранах;
- первый заголовок остаётся в теле видимым `h1`, а не только в `<title>`.

PDF (`render._LATEX_HEADER`, `render.PDF_GEOMETRY`, A4 с полями 1.8 см):
- плавучие `figure` заменяются на неразрывные врезки: LaTeX ставил рисунок
  туда, где он не помещался, и низ страницы обрезался;
- язык конспекта (`--output-language`) передаётся в babel, включая правила
  переноса и подписи «Рис. N»; без них длинные слова вылезали за поля.

HTML/PDF можно отключить флагом `--skip-render` (например, когда pandoc
или lualatex не установлены).

## Разработка

- Код — Python 3.13+, пакет в `src/absorbent/`, каждый этап — отдельный
  модуль (`extract.py`, `dedup.py`, `transcribe.py`, `describe.py`,
