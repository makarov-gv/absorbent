# Backlog

Отложенные идеи, не вошедшие в первую версию:

- Кадрирование и аннотирование ключевых кадров (стрелки, подписи).
- Скачивание интернет-иллюстраций там, где они проясняют материал.
- Полный агентный цикл: модель сама запрашивает дополнительные кадры по
  мере необходимости как уточнение двухпроходной схемы.
- Отбор «устоявшихся» кадров вместо жадного удержания: на анимированной
  презентации жадное правило (удержать кадр, далёкий от последнего
  удержанного) ловит промежуточные/размытые кадры анимации и шумные
  кратковременные состояния (список участников ВКС, камера лектора). Урок
  лекции Маголего: 33 из 91 пары keyframe идут с шагом < 5 с. Критерий:
  кадр = контент только если он продержался заметное время; промежуточные
  состояния отбрасывать. Решение — кластерный отбор по pHash (метрика
  Хэмминга, эмбеддинги не нужны): устойчивый слайд образует плотный кластер
  одинаковых кадров, из кластера берётся ядро (чистый кадр без артефактов),
  а короткие/переходные группы уходят как шум.
- Параллельная обработка кадров и аудиодорожки: независимые этапы
  (извлечение/дедупликация кадров и распознавание речи) выполняются
  одновременно, что сокращает общее время прогона.
- Борьба с галлюцинациями whisper: на реальной записи лекции первые ~35
  минут turbo выдал петлю «Thank you.» поверх реальной речи; гипотезы для
  проверки — VAD-фильтр тишины, `condition_on_previous_text=False`,
  пер-чанковая транскрипция.
- Пер-сегментная разметка языка в transcript.json: whisper отдаёт один язык
  на весь файл, а лекции бывают двуязычными; язык фрагмента можно оценивать
  по кириллице/латинице (или отдельным вызовом STT) и помечать в сегментах.
- Проверка непустого ответа LLM на этапе синтеза. На реальном прогоне лекции
  (2:33, `deepseek-v4-flash`, 1720 сегментов транскрипта и 94 кадра) синтез
  вернул пустой `content`, `run_synthesize` записал пустые `notes.md` и
  `notes.pdf`, а конвейер всё равно отчитался «готово»; `notes.html` при этом
  собрался из пустого Markdown (34 КБ). Тот же запрос, повторённый вручную,
  вернул 41 КБ (`finish_reason=stop`, 15 257 токенов ответа), так что дело не
  в размере запроса — похоже на разовый сбой провайдера. Предложение: считать
  пустой (или состоящий из пробелов) ответ ошибкой — падать с понятным
  сообщением и/или повторять запрос, а не писать пустой файл; заодно не
  запускать `render_all` для пустого результата. Обходной путь без правки
  кода — перезапуск только синтеза по кэшу:
  `absorbent <video> --skip-stt --skip-frames --skip-describe`.
